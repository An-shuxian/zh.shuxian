# 張淑賢 - 數位多媒體個人作品集 (Personal Portfolio)

這是一個為數位多媒體系學生「張淑賢」量身打造的單頁式個人介紹網站。
本專案升級為具備專業 UI 設計的豐富版，保留了專屬的「薄荷綠與柔和粉紅」色系以及圓潤可愛的字體，並加入了現代感的毛玻璃特效與動態捲動展示，完美呈現出大學生充滿活力、創意與專業的個人特色。

## ✨ 全新網站特色 (New Features)

* **專業的 UI 視覺**：採用流行的毛玻璃（Glassmorphism）置頂導覽列，搭配精緻的漸層背景與優雅的卡片陰影。
* **生動的動態效果**：內建順暢的頁面錨點跳轉，以及隨著頁面往下捲動時觸發的平滑浮現動畫（Scroll Reveal），大幅提升網站的高級感。
* **豐富的內容區塊**：
  * **首頁 (Hero)**：吸睛的個人標語與自我介紹。
  * **關於我 (About)**：專屬的大頭貼版位與核心理念。
  * **技能與目標 (Skills)**：透過進度條與標籤雲，視覺化展示「繪畫創作」與「小說寫作」技能。
  * **生活點滴 (Life Gallery)**：專屬的相片牆，可隨時替換或新增您的生活照與攝影作品。
  * **聯繫方式 (Contact)**：包含信箱、電話、Facebook 資訊，並附帶一個擬真的快速留言表單。

## 🛠️ 使用技術 (Technologies Used)

* **HTML5**：網頁語意化結構。
* **CSS3 (Tailwind CSS)**：透過 Tailwind CSS CDN 快速建構自適應排版、客製化色彩與自訂樣式。
* **Vanilla JavaScript**：負責處理手機版導覽列、導覽列滾動特效、以及 Intersection Observer 頁面滾動動畫。
* **字體與圖示**：
  * [Google Fonts](https://fonts.google.com/) (Mali 標題字體, Nunito 英文內文, Noto Sans TC 中文內文)
  * [FontAwesome 6](https://fontawesome.com/) (向量圖示庫)

## 📂 檔案結構與圖片顯示說明 (How to Run & Show Images)

本專案採用最簡化的單一檔案結構，極易部署：

```text
📁 MyPortfolio (您可以自訂資料夾名稱)
 ├── 📄 index.html        # 網站主程式碼
 ├── 📄 1000042611.jpg    # 您的專屬生活照 (必須放在這裡)
 └── 📄 README.md         # 專案說明文件 (本檔案)
```

### ⚠️ 重要：如何讓您的照片正常顯示？

如果您發現網頁上的照片變成「破圖」圖示，請務必按照以下步驟操作：

1. **建立專屬資料夾**：在您的電腦（如桌面）建立一個新的資料夾。
2. **放置檔案**：將下載的 `index.html` 與您的照片檔案 `1000042611.jpg` 放在**同一個資料夾**內。
3. **確認副檔名**：確保照片的檔名與大小寫完全相符（例如 `.jpg` 不能變成 `.PNG`）。
4. **開啟網頁**：直接點擊兩下 `index.html` 在瀏覽器中開啟，您的照片就會成功顯示在「生活點滴」區塊了！
*(註：若要替換其他照片，只需用文字編輯器開啟 `index.html`，尋找 `placehold.co` 網址並替換為您新照片的檔名即可。)*
